# Маршрут «Синяя Рука» — веб-приложение

Лёгкая мобильная веб-версия 13-дневного маршрута (22 сентября — 4 октября 2026).
Чистый HTML/CSS/JS, без сборки, без бэкенда.

## Структура

```
index.html               — единственная HTML-страница (приложение — SPA)
css/style.css             — все стили (шрифт — Cormorant Garamond, подключается из Google Fonts)
js/data.js                 — ⭐ тексты всех 13 дней (Dreamspell-шапка + вопросы/практики/след)
js/intro.js                — текст вступительного экрана
js/app.js                   — вся логика (время, состояния дней, анимации, карточка дня, финал)
assets/                      — изображения и видео (оптимизированы для мобильного веба)
assets/headers/day_01.webp…day_13.webp — шапки 16:9 карточек дня
vercel.json, _redirects      — конфиги для деплоя (см. ниже)
```

## Как это работает

- **Три входа, один маршрут.** Режим определяется по URL и один раз запоминается в localStorage браузера:
  - Наблюдение: `/nablyudenie` (или `/observation`, или `?mode=observation`)
  - Путешествие: `/puteshestvie` (или `/journey`, или `?mode=journey`)
  - Погружение: `/pogruzhenie` (или `/immersion`, или `?mode=immersion`)

  Контент дня одинаков во всех трёх режимах, отличается только блок «След дня».

- **Время маршрута** считается по Москве (UTC+3). До 22.09 — экран ожидания. С 22.09 по 04.10 — открыт
  только текущий день, смена происходит строго в 00:00 МСК. Если в этот момент у пользователя была
  открыта карточка старого дня — она автоматически закрывается, и сцена перерисовывается под новый день.
  После 04.10 — у всех финальное завершённое состояние, без возврата к карте дней.

- **Карточка дня — один шаблон**, данные подставляются из `js/data.js` (без отдельных HTML на каждый день).
  Дни 1–12 показывают: шапку 16:9, Dreamspell-блок (Kin/Печать/Тон/склейка), главный вопрос, закрытый
  выбор практики A/B и (после выбора) След дня. День 13 — тот же шаблон без практик и без Telegram-следа:
  Dreamspell-блок + вопрос «Что заберёшь с собой, завершая маршрут?» + кнопка «Собрать маршрут», которая
  ведёт в финальную видео-сцену.

- **Практика A/B — закрытый выбор.** До выбора видны два одинаковых по виду закрытых пункта «Практика A»
  и «Практика B», без названий и без подсказок. После выбора одной — она раскрывается с настоящим
  названием и полным текстом (с сохранением абзацев, списков и выделений из брифа), вторая гаснет и
  становится недоступной на весь день. Выбор хранится в localStorage на ключ `bh_practice_choice_day_N`
  (например, `bh_practice_choice_day_5 = "A"`) — только в этом браузере/устройстве, без сервера и аккаунтов.
  При повторном входе в тот же день выбор восстанавливается мгновенно, без повторной анимации.

- **Внутренняя искорка.** При первом выборе практики в её сторону запускается мягкая золотая капля
  (~3 сек), которая «стекает» вниз и открывает След дня. Это отдельная анимация от внешнего импульса
  на ладони (см. ниже) и проигрывается только один раз — при первом выборе.

- **Внешний импульс на ладони** (~2.5 сек) — как и раньше, проигрывается при **каждом** входе в
  активную точку текущего дня, вне зависимости от того, выбирал ли пользователь практику.

- **Ничего не хранится на сервере.** LocalStorage хранит: просмотрено ли вступление, в какой день
  пользователь уже входил сегодня, и выбор практики по каждому дню. Ответы на практики и След нигде
  не сохраняются — ни локально, ни на сервере.

## Тексты дней (`js/data.js`)

Тексты Дней 1–13 перенесены дословно из присланных брифов (`SOURCE_BRIEFS/01_cards_days_1-12.md` и
`02_dreamspell_headers_days_1-13.md`) — без сокращений и без переписывания. Если текст какого-то дня
изменится, правьте прямо соответствующие поля в объекте `BH_DAYS` этого файла:

- `kin`, `seal.name/short`, `tone.name/short`, `daySynthesis` — для всех 13 дней;
- `mainQuestion`, `practiceA.title/body`, `practiceB.title/body`, `traceQuestion` — для Дней 1–12;
- `finalQuestion`, `finalCta` — только для Дня 13.

Внутри `body` практик поддерживается лёгкая разметка (её понимает `renderRich()` в `app.js`):
пустая строка — новый абзац, строки, начинающиеся с `- ` — маркированный список, с `1. ` — нумерованный,
`**текст**` — полужирное выделение.

## Временный HTML-оверлей финальных фраз (Day 13)

Сейчас `assets/day13_namaste.mp4` и `assets/day13_final.jpg` не содержат финальные фразы
(«Маршрут пройден» / «Увидимся за поворотом…» / «13 MIRRORS» / «Калейдоскоп твоих миров») встроенными
в кадр — поэтому они по-прежнему рисуются HTML-оверлеем поверх видео и стоп-кадра. Это временное решение,
явно помечено в коде комментариями `TEMP_OVERLAY` в `js/app.js` (методы `finishFinaleScene()` и
`showCompletedFinale()`). Как только будет передан обновлённый видео/стоп-кадр со вшитым текстом —
эти оверлеи нужно убрать, оставив только сам асеет.

## Проверка на разных датах (без перевода системных часов)

Добавьте к адресу `?debugNow=2026-09-25T10:00:00`, чтобы приложение думало, что сейчас это время
(парсится как московское). Контрольные точки из ТЗ:

- `?debugNow=2026-09-21T10:00:00` — экран ожидания;
- `?debugNow=2026-09-22T10:00:00` — День 1;
- `?debugNow=2026-09-28T10:00:00` — День 7 (работает как любой обычный день, без исключений);
- `?debugNow=2026-10-03T10:00:00` — День 12;
- `?debugNow=2026-10-04T10:00:00` — День 13 (карта сборки → видео);
- `?debugNow=2026-10-05T10:00:00` — завершённый маршрут.

## Деплой

Статический сайт — подходит любой статический хостинг (Vercel, Netlify, Cloudflare Pages, обычный
nginx). Единственное условие: **любой путь должен отдавать `index.html`**, чтобы работали три входные
ссылки `/nablyudenie`, `/puteshestvie`, `/pogruzhenie` (SPA-роутинг на клиенте).

- **Vercel**: конфиг уже есть (`vercel.json`).
- **Netlify**: конфиг уже есть (`_redirects`).
- **Свой сервер / nginx**: настроить `try_files $uri /index.html;`.

Шрифт Cormorant Garamond подключается из Google Fonts по ссылке в `index.html` — нужен доступ в
интернет у пользователя (обычная практика, локальные файлы шрифта в пакет не включены по ТЗ).

## Что сознательно не сделано

Нет Supabase, нет бэкенда, нет хранения ответов, нет дневника, нет кодов доступа, нет регистрации,
нет личного кабинета, нет админки, нет архива прошедших дней, нет конструктора маршрутов и никакой
аналитики «на будущее». Рисунок на сцене не зависит от действий пользователя — только от календарной
даты. Нет отдельных HTML-страниц под каждый день — один шаблон карточки на все 13 дней.

## Ограничение автоплея видео на iOS

Финальное видео Day 13 запускается автоматически (без звука, `playsinline`) сразу после нажатия
«Собрать маршрут» — по спецификации это происходит по жесту пользователя, так что автоплей должен
пройти на всех современных мобильных браузерах. Если браузер всё же заблокирует автоплей — показывается
запасная кнопка «Продолжить»; если видео вообще не может проиграться (неподдерживаемый формат) —
приложение не оставляет пользователя на чёрном экране, а сразу показывает финальный кадр с текстом.
